# Day2-student-score-Analyzer🎓 Student Score Analyzer

📌 Description

This project analyzes student scores using Python. It calculates key statistics like average, median, highest, and lowest marks, and helps in understanding student performance.

🚀 Features

- Calculate average score
- Find highest and lowest marks
- Compute median
- Assign grades based on performance
- Simple and efficient logic

🛠️ Technologies Used

- Python

▶️ How to Run

1. Clone the repository:
   git clone https://github.com/your-username/student-score-analyzer.git

2. Navigate to the folder:
   cd student-score-analyzer

3. Run the program:
   python main.py

📊 Example Output

Average Score: 78
Median Score: 80
Highest Score: 95
Lowest Score: 50
